UI 미리보기 대략적인 목업 · 아직 만들지 않음

배경은 Unity에서 찍은 실제 게임 화면이에요. 버튼·글자 위치와 흐름을 보는 용도라 색과 모양은 만들 때 다듬어요. UI 글자는 기본 폰트에 한글이 없어 영어예요.

MAIN MENU→ START → PLAY→ 떨어지면 → GAME OVER→ RETRY / MAIN MENU / QUIT

① 메인 메뉴 새로

BEST 1500
HANBOK
COIN HOP
VOXEL SURVIVAL
START
QUIT
WASD / ARROWS : MOVE  ·  SPACE : JUMP

게임을 켜면 먼저 나오는 화면. START를 눌러야 게임이 시작돼요. 뒤에는 맵과 캐릭터가 흐리게 보이고, 오른쪽 위에 최고 점수를 보여요. 제목은 임시예요.

② 플레이 중 지금과 같음

SCORE 300
BEST 1500

지금 게임 화면 그대로예요. 왼쪽 위 점수, 오른쪽 위 최고 점수.

③-A 게임 오버: 버튼만 추천

GAME OVER
SCORE1600
BEST1600
NEW BEST!
RETRY
MAIN MENU
QUIT

자동으로 재시작하지 않고, 플레이어가 고를 때까지 기다려요. 이번 점수와 최고 점수를 보여 주고, 기록을 넘으면 NEW BEST!를 띄워요.

③-B 게임 오버: 3초 뒤 자동 재시작 + 버튼

GAME OVER
SCORE1200
BEST1600
RETRY IN 3
MAIN MENU
QUIT

지금처럼 3초 뒤 자동으로 다시 시작하되, 그 전에 MAIN MENU나 QUIT를 누를 수 있어요.

버튼이 하는 일

버튼하는 일참고
START메인 메뉴에서 게임 시작 (구멍·코인·점수가 이때부터 움직임)그 전에는 캐릭터를 움직일 수 없음
RETRY바로 다시 시작 (메인 메뉴를 거치지 않음)③-A에만 있음
MAIN MENU메인 메뉴로 나가기
QUIT게임 종료Unity 에디터에서 테스트할 때는 플레이 모드가 멈춤 (실제 종료는 빌드한 게임에서만)

조작: 마우스로 버튼 클릭. 키보드(Enter·방향키)로도 고를 수 있게 할지는 정해 주세요.
