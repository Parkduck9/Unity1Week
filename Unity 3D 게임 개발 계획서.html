항목결정

개발 단계

  1. 0

    Unity 3D 프로젝트 생성

    • Unity 6 LTS, URP 템플릿
    • Input System 패키지 설정
    • 폴더 구조: Scripts Prefabs Materials Animations Scenes
  2. 1

    3D 복셀 캐릭터 생성

    • 캐릭터: 한복풍 옷을 입은 여자 캐릭터 (사용자 레퍼런스 이미지 기준) — 긴 검은 머리, 붉은 저고리와 갈색 깃, 흰 프릴 퍼프 소매, 남색 허리띠, 발목까지 오는 분홍 치마
    • Cube를 조합해 캐릭터 제작
    • 파츠 분리: 머리 / 몸 / 왼팔 / 오른팔 / 왼다리 / 오른다리 (애니메이션용)
    • 프리팹으로 저장
  3. 2

    4x4 타일맵 + 이동 / 점프 + 따라가는 카메라

    • 1 unit 크기 타일로 4x4 맵 구성, 가운데 대각선 2칸은 구멍 (타일 14개, 초록 체커무늬)
    • Rigidbody 기반 캐릭터 이동(WASD / 방향키, 초당 3칸), 점프(Space, 높이 1.2칸)
    • 이동 방향으로 캐릭터 회전, 시작 시 카메라 쪽을 바라봄
    • 따라가는 카메라: 고정 각도 쿼터뷰로 부드럽게 따라감 (W = 화면 위쪽)
  4. 3

    Idle / Walk / Jump 애니메이션

    • Animator Controller: Idle ↔ Walk, Any State → Jump (공중에 있을 때, 점프하지 않고 떨어질 때 포함)
    • 파츠 Transform 키프레임으로 제작
    • Idle: 숨쉬기 + 머리 살짝 기울이기
    • Walk: 팔(35°)·다리(15°) 교차 스윙 + 몸 튐 (다리는 치마를 뚫지 않게 작게)
    • Jump: 팔 올리기 + 몸 늘이기
  5. 4

    아이템 추가

    • 아이템: 금화(엽전 느낌, 가운데 네모 구멍), 지름 0.4, 바닥에서 0.5 높이
    • 아이템 3개를 타일 위에 배치 (두 구멍 사이 2곳 + 오른쪽 위 모서리)
    • 회전 + 위아래로 떠다니는 연출
    • Trigger Collider로 획득 → 개수 증가, 작아지며 떠올라 사라짐
    • UI: ITEM 0 / 3 (왼쪽 위)
  6. 5

    게임 종료 / 성공 판정 (GameManager)

    • 실패: 캐릭터 y < -5 → GAME OVER 문구 표시
    • 성공: 아이템 3개 모두 획득 → CLEAR 문구 표시
    • 종료되면 플레이어 입력 막기
  7. 6

    3초 후 재시작

    • 종료 후 카운트다운 표시: 3 → 2 → 1
    • 코루틴으로 기다린 뒤 SceneManager.LoadScene으로 현재 씬 다시 불러오기

게임 상태 흐름

Playing → Clear / GameOver → 카운트다운 3초 → 씬 재시작

Clear 또는 GameOver가 되면 입력을 막고, 카운트다운이 끝나면 Playing부터 다시 시작합니다.
