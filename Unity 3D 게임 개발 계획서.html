Unity 6 LTS URP Input System

확정 사항

항목결정
카메라플레이어를 따라가는 카메라
아이템기본 3개
UI아이템 개수, GAME OVER / CLEAR 문구, 재시작 카운트다운
입력WASD / 방향키 이동, Space 점프

개발 단계

  1. 0

    Unity 3D 프로젝트 생성

    • Unity 6 LTS, URP 템플릿
    • Input System 패키지 설정
    • 폴더 구조: Scripts Prefabs Materials Animations Scenes
  2. 1

    3D 복셀 캐릭터 생성

    • Cube를 조합해 캐릭터 제작
    • 파츠 분리: 머리 / 몸 / 왼팔 / 오른팔 / 왼다리 / 오른다리 (애니메이션용)
    • 프리팹으로 저장
  3. 2

    4x4 타일맵 + 이동 / 점프 + 따라가는 카메라

    • 1 unit 크기 타일 16개로 4x4 맵 구성
    • 캐릭터 이동(WASD / 방향키), 점프(Space)
    • 이동 방향으로 캐릭터 회전
    • 따라가는 카메라: 플레이어 뒤쪽 위에서 부드럽게 따라감
  4. 3

    Idle / Walk / Jump 애니메이션

    • Animator Controller: Idle ↔ Walk, Any State → Jump
    • 파츠 Transform 키프레임으로 제작
    • Walk: 팔·다리 교차 스윙 / Jump: 팔 올리기, 다리 모으기
  5. 4

    아이템 추가

    • 아이템 3개를 타일 위에 배치
    • 회전 + 위아래로 떠다니는 연출
    • Trigger Collider로 획득 → 개수 증가
    • UI: 아이템 0 / 3
  6. 5

    게임 종료 / 성공 판정 (GameManager)

    • 실패: 캐릭터 y < -5 → GAME OVER 문구 표시
    • 성공: 아이템 3개 모두 획득 → CLEAR 문구 표시
    • 종료되면 플레이어 입력 막기
  7. 6

    3초 후 재시작

    • 종료 후 카운트다운 표시: 3 → 2 → 1
    • 코루틴으로 기다린 뒤 SceneManager.LoadScene으로 현재 씬 다시 불러오기

게임 상태 흐름

Playing → Clear / GameOver → 카운트다운 3초 → 씬 재시작

Clear 또는 GameOver가 되면 입력을 막고, 카운트다운이 끝나면 Playing부터 다시 시작합니다.
